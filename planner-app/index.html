Reminders

Constant Reminder: when it is on, a task you ticked for constant reminders will keep reminding you — a banner, a sound, and a notification — until you mark it Done. It repeats at the interval below, and stops the moment the task is done.

Honest limit: this is a web app with no server, so reminders can only ring while the app is open (or installed and running). It cannot wake a fully closed phone the way a built-in alarm app can. Keep the app open for constant reminders to keep coming.

Voice Capture

Tap the mic, speak a task out loud, check what it heard, then tap Save as task. You can edit it in the form below before saving, if you like.

Voice capture works in Chrome and Edge on Windows, and in Safari on newer iPhones. If your browser does not support it, the mic button will tell you, and you can type the task instead.

Cross-device sync

Sync this planner between your iPhone, Windows computer, and other devices using a private GitHub Gist. This runs in your browser only — no separate server is involved.

Privacy note: the gist is private, but do not put highly sensitive information in the planner. Your token below stays on this device only and is never included in an export file.

Warning: never share this token with anyone. It is stored only in this device's local storage. A token with the gist scope is needed. If you do not have one, create one in GitHub Settings > Developer settings > Personal access tokens.

Manual fallback — Export / Import JSON

If you do not want to use Gist sync, this still works: export a file on one device and import it on the other. This does not include your token.

How merging works on Pull / Sync Now: for tasks, habits, notes, lists, and dates, the newer item (by its last-edited time) wins. Local items are not silently deleted — an item that exists only on this device is kept. Items you delete are remembered, so a deleted item is not brought back by another device.
