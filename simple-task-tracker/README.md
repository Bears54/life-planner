# Simple Task Tracker

A simple task tracker inspired by the FridayGrids Simple Task Tracker Spreadsheet for Google Sheets. This is an original recreation, not a copy of that product.

## Use it on iPhone

Open the live Google Sheet in the Google Sheets app on your iPhone:

https://docs.google.com/spreadsheets/d/1PfkUNPYJvVMdAW2o5SHkqxKKqcN8jfr-Ta1XYACLG3U/edit

Start with Dashboard, then Task List. Add the sheet to your Home Screen from the Sheets app for one-tap access.

## Tabs

- Setup - your name, categories, priorities, statuses, assignees, and how-to-use
- Task List - the single source of truth: Status, Task, Description, Category, Priority, Assignee, Due Date, Days Left
- Dashboard - Total, Closed, Overdue, Due Today, Total Progress, Forecast (Tomorrow / Next 7 Days / This Month), Upcoming Tasks, Task Status counts
- Weekly Planner - Oct 26 to Nov 1, 2026, with completion % and tasks per day
- Monthly Planner - October 2026, tasks by date with Done / Total

## How it works

Add a task once in Task List. Dashboard, Weekly and Monthly update automatically with COUNTIF / COUNTIFS / FILTER formulas. Mark a task Completed and all counts and progress update.
